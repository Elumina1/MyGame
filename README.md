# Угадай кто?

MVP браузерной multiplayer-игры на React, TypeScript, Vite, Express и Socket.IO. Комнаты и секретные персонажи хранятся только в памяти Node.js.

## Требования
Node.js 18+ и npm.

## Установка и запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173. Для теста создайте игру в одном окне, скопируйте код и присоединитесь во втором. Выберите персонажей, нажмите «Готов», затем задавайте вопросы по очереди. `npm run build` проверяет production-сборку клиента.

Архитектура: `client` — React UI и локальные закрытые карточки; `server` — Express health endpoint, Socket.IO и authoritative-состояние комнат. Токен игрока и код комнаты сохраняются в localStorage для простого reconnect.

## Ограничения MVP

Нет базы данных, аккаунтов и восстановления после перезапуска сервера. Сообщения — простой текстовый обмен, сервер не различает семантику вопроса и ответа. При reconnect используется та же вкладка/токен; пустые комнаты удаляются через 2 минуты.
